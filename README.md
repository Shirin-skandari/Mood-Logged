# 💗 Mood Logged

> A little space for your feelings.

Mood Logged is a simple mood tracking app I built with HTML, CSS, and JavaScript.

You can choose how you're feeling, write a short note, and save it to your mood history. Your entries are stored in the browser, so they stay there even after refreshing the page.

## ✨ What you can do

* Choose between **Happy, Sad, Excited, and Angry**
* Get a different message for each mood
* Write a short note about your day
* Save your moods with the date and time
* View your previous mood entries
* Delete entries whenever you want
* Use the app comfortably on different screen sizes

## 🛠️ Built with

* HTML
* CSS
* JavaScript
* LocalStorage

## 🚀 Running the project

No setup is needed.

Just open `index.html` in your browser and start logging your moods.

## 🎯 Why I built it

I built Mood Logged as a practice project to improve my JavaScript skills and get more comfortable working with the DOM, events, arrays, objects, and LocalStorage.

It started as a small idea and gradually turned into a more complete project as I added things like mood history, validation, delete functionality, and responsive design.
